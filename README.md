# Superstore Sales Dashboard

An end-to-end sales analysis project using **SQL and Tableau** to clean, analyze, and visualize Superstore sales data. The project focuses on identifying trends in sales and profitability across customer segments, regions, and time periods.

## Project Overview

This project analyzes Superstore sales data to answer questions such as:

* Which customer segments generate the most sales?
* Which regions perform best in terms of sales and profitability?
* How does profitability change over time?
* Which areas may require further investigation based on low profit margins?

The analysis was performed using SQL, with the results visualized in an interactive Tableau dashboard.

## Tools & Technologies

* **SQL** — Data cleaning and exploratory analysis
* **PostgreSQL** — Database management and querying
* **Tableau** — Data visualization and dashboard development
* **CSV** — Source data

## Data Cleaning & Analysis

SQL was used to prepare the dataset and perform exploratory analysis, including:

* Cleaning and transforming the source data
* Examining sales and profitability trends
* Comparing customer segments
* Analyzing regional performance
* Calculating and comparing profit margins
* Identifying areas of strong and weak performance

## Key Findings

* **Consumer was the strongest customer segment**, generating substantially more sales than the other segments.
* **The West region had the highest total sales** among the four regions.
* **Profitability improved toward the end of 2016**, with a profit margin of **13.05%**, compared with the overall average of **12.47%**.
* **The Central region had the lowest profit margin**, making it an area that warrants further investigation into the factors affecting profitability.
